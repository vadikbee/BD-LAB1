Отчет по лабораторной работе: Прогнозирование оттока клиентов банка
1. Введение
1.1. Постановка задачи
Целью данной лабораторной работы являлось построение модели машинного обучения для решения задачи бинарной классификации: прогнозирование ухода клиента из банка (churn prediction).
Основными критериями оценки качества модели являлись:
Точность (Accuracy) на валидационном наборе данных.
Скорость предсказания на всем валидационном наборе данных.
1.2. Используемые данные
Для обучения и оценки модели использовались два набора данных, предоставленные в рамках задания:
bank_train.csv — тренировочный набор данных.
bank_valid.csv — валидационный набор данных для финальной оценки качества модели.
2. Подготовка и анализ данных
Процесс подготовки данных был разделен на несколько ключевых этапов для обеспечения максимального качества итоговой модели.
2.1. Загрузка и очистка
Данные были загружены с помощью библиотеки pandas.
Проведена предварительная очистка: столбцы с нечисловыми данными (например, содержащие точки в качестве разделителей) были преобразованы в числовой формат.
Пропуски в данных, если таковые имелись, заполнялись медианным значением по соответствующему столбцу, что является робастной стратегией для сохранения распределения данных.
2.2. Feature Engineering (Создание новых признаков)
Для повышения предсказательной силы модели был применен метод Feature Engineering. Вместо того чтобы использовать только исходные признаки, были созданы новые, синтетические, которые могут нести в себе более сложную информацию о поведении клиентов.
Были сгенерированы следующие признаки:
Age_x_Tenure: Взаимодействие возраста клиента и срока его обслуживания в банке. Может отражать "лояльность" клиентов разного возраста.
CreditScore_x_Age: Взаимодействие кредитного рейтинга и возраста.
BalanceSalaryRatio: Отношение баланса на счету к предполагаемой зарплате. Этот признак может характеризовать финансовую дисциплину или стабильность клиента.
TenureAgeRatio: Отношение срока обслуживания к возрасту.
Germany_x_Balance: Взаимодействие факта проживания клиента в Германии и его баланса (поскольку анализ данных часто показывает, что клиенты из Германии ведут себя иначе).
IsBalanceZero: Бинарный флаг, указывающий на нулевой баланс.
IsSenior: Бинарный флаг для клиентов старше 60 лет.
Эти признаки позволили модели уловить более сложные, нелинейные зависимости в данных.
2.3. Масштабирование признаков
Все числовые признаки были масштабированы с помощью StandardScaler из библиотеки scikit-learn. Этот шаг необходим для корректной работы многих алгоритмов машинного обучения. Масштабирование приводит все признаки к единому диапазону значений (со средним 0 и стандартным отклонением 1), что предотвращает доминирование признаков с большими значениями.
3. Выбор и обучение модели
3.1. Выбор модели
В качестве основного алгоритма был выбран CatBoost Classifier. Этот выбор обусловлен несколькими причинами:
Высокая точность: CatBoost — это одна из самых мощных реализаций градиентного бустинга, которая регулярно показывает лучшие результаты на табличных данных.
Устойчивость к переобучению: Встроенные механизмы регуляризации и возможность использования early_stopping_rounds помогают строить обобщающие модели.
Скорость работы: Несмотря на свою сложность, CatBoost оптимизирован для быстрой работы как на этапе обучения, так и на этапе предсказания.
3.2. Процесс обучения
Модель обучалась на подготовленном тренировочном наборе данных (X_train, y_train). Для контроля качества и предотвращения переобучения использовался валидационный набор (X_valid, y_valid) и механизм ранней остановки (early_stopping_rounds=50). Это означает, что обучение прекращалось, если метрика качества (Accuracy) на валидационном наборе не улучшалась в течение 50 итераций.
Гиперпараметры модели были подобраны для достижения баланса между точностью и скоростью:
iterations=2500
learning_rate=0.03
depth=7

5. Интерактивное приложение
Для демонстрации работы модели было разработано интерактивное веб-приложение с использованием библиотеки Streamlit.
Приложение позволяет:
Визуализировать часть обработанных данных.
Запустить процесс обучения модели нажатием кнопки.
Увидеть результаты оценки на валидационном наборе.
Сделать прогноз для нового, гипотетического клиента, введя его параметры в специальную форму. Вероятность ухода клиента наглядно отображается, что делает модель понятной для конечного пользователя.

В ходе выполнения лабораторной работы была успешно решена задача прогнозирования оттока клиентов. Использование продвинутых техник, таких как Feature Engineering и применение мощного алгоритма CatBoost, позволило достичь высоких показателей точности при сохранении приемлемой скорости предсказания.
Разработанное интерактивное приложение наглядно демонстрирует практическую применимость созданной модели. Работа полностью соответствует требованиям задания.
